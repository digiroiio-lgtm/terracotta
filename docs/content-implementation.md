# TERRACOTTA – Content & SEO Implementation Notes

Phase: content, product data and SEO only. No images, CSS, layout or behaviour were changed.

## How the site is built

- `site/data/products.json` – single source of truth: 6 categories, 12 product types, 12 colours, SEO titles, URLs.
- `site/index.html` – homepage (edited in place).
- `site/tools/build_pages.py` – generates all other pages from the data file. It reuses the homepage header, mega menu, pre-footer and footer, so every page keeps the existing design.
  Run `python3 site/tools/build_pages.py` after changing the data file or the homepage navigation.
- `site/sitemap.xml`, `site/robots.txt` – generated by the same script.
